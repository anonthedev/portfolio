01 · work

things i've built, and why they were interesting.

  1. athel

    research agent · 2026

    Python · LangGraph · FastAPI · Electron

    a desktop app that turns one question into a sourced markdown report. you ask a topic in the window, edit the questions it drafts, and it searches the web, reads the html and pdfs it finds, then writes the report to disk. pdf pages are split into passages and ranked by embedding, so the extractor only sees the top 12. on a labeled set, the target fact held on 24 of 25 papers.

    github

  2. openrabbit

    code review · 2026

    TypeScript · tree-sitter · sqlite-vec · OpenRouter

    a self-hosted github app that reviews pull requests. when a pr opens or updates, it reads the diff, looks up related code in the base commit, and posts a comment. it flags bugs, security issues, duplicated logic, work outside the pr's goal, load problems, and breaks with a pattern already in the repo. a small safe fix is posted as a github suggestion. if none of that applies, it leaves a short note and stops. the lookup splits the base commit into tree-sitter symbols, embeds them in sqlite-vec, and pulls the nearest 5 before the model writes.

    github

  3. slayshot

    video pipeline · shut down

    Next.js · Supabase · Python · Modal · Inngest

    turned a long video, or a youtube link, into vertical clips you could post. it transcribed the source, scored moments that could stand on their own, cut those sections, reframed them by tracking the active speaker, and burned in word-timed captions. the hosted product is shut down. the pipeline is open source under its old repo name, omenclip.

    github slayshot.xyz

  4. readica

    research tool · 2024–present

    Next.js · Supabase · Node.js · PDF-lib · Tiptap

    a reading system for research pdfs. upload a paper or save one from search, tag it, and mark whether you've read it. the reader opens the pdf with search and highlights, and notes stay attached to that paper. you can also ask it to find papers on a topic, review the candidates, and add the useful ones to the library.

    github readica.pro
