01 · work

what i've built.

  1. athel

    research agent · 2026

    Python · LangGraph · FastAPI · Electron

    a deep research agent that runs locally. you edit the questions it drafts. it searches the web, reads the pages and pdfs, and saves the report on disk. pdf text is ranked by embedding, and the extractor only sees the top 12 passages. on a labeled set, the target fact held on 24 of 25 papers.

    github

  2. openrabbit

    code review · 2026

    TypeScript · tree-sitter · sqlite-vec · OpenRouter

    a self-hosted github app that reviews pull requests. when a pr opens or updates, it reads the diff, finds related code in the base commit, and posts a comment. it calls out bugs, security issues, and duplicated logic. a small safe fix is posted as a github suggestion. a clean diff gets a short note. the lookup embeds tree-sitter symbols from the base commit in sqlite-vec and pulls the nearest 5 before it writes.

    github

  3. slayshot

    video pipeline · shut down

    Next.js · Supabase · Python · Modal · Inngest

    turned a long video or a youtube link into a vertical clip with word-timed captions. transcription found the words. moment scoring picked sections that can stand alone. active-speaker detection reframed the shot. the hosted product is shut down. the open-source pipeline is in the omenclip repo.

    github slayshot.xyz

  4. readica

    research tool · 2024–present

    Next.js · Supabase · Node.js · PDF-lib · Tiptap

    a library for research pdfs. you upload a paper or save one from search, tag it, and mark whether you have read it. search and highlights live in the reader. notes stay on that paper. you can ask for papers on a topic and add the ones you want.

    github readica.pro
